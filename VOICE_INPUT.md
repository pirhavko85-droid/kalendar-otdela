# Голосовой черновик — проба от 08.11.2026

Роман выбрал сначала проверить микрофон и карточку, без прямой записи в Sheets.
Во вкладке «Мероприятия» есть «🎤 Голосовой черновик».

1. «Подготовить микрофон» загружает Transformers.js 3.8.1 с jsDelivr и
   многоязычную модель onnx-community/whisper-tiny (q8) с Hugging Face.
2. После готовности нажать «Начать запись» и разрешить микрофон браузеру.
   Запись ограничена 45 секундами; закрытие карточки останавливает микрофон.
3. «Остановить» запускает локальное распознавание на CPU через WebAssembly
   в отдельном Worker. Аудио и текст не отправляются на сервер распознавания.
4. Проверить текст, название, дату, время; участников выбрать вручную.
5. «Скопировать для внесения в таблицу» создаёт текст запроса для рабочего чата.
   Не меняет Google Sheets, localStorage базы или опубликованный снимок.

Первый запуск требует интернета и загрузки десятков МБ. Последующие загрузки
могут использовать кэш библиотеки/браузера; браузер вправе очистить его.
Загрузка и распознавание имеют таймауты. При ошибке доступен обычный текст,
в том числе системная диктовка клавиатуры телефона. Платного API и ключей нет.
Фактические скорость, качество русского, имён и сокращений, запись через Safari
на конкретном iPhone требуют проверки на устройствах Романа и операторов.

Разбор текста ограничен: сегодня/завтра/послезавтра по Москве, даты цифрами
или с русским названием месяца, время HH:MM или «в 11 часов». Пропущенные
поля остаются пустыми, неверные даты отклоняются. Числа словами не обещаются.
Название сохраняет всю фразу для ручного редактирования. Все действия — черновик.

Исходники: voice-draft.js (чистые функции), voice-input.js (UI/микрофон),
voice-worker.js (Whisper). Проверки: node --test tools/voice-draft.test.cjs.
Модель: https://huggingface.co/onnx-community/whisper-tiny
Библиотека: https://github.com/huggingface/transformers.js (Apache-2.0).
Исходная модель Whisper: https://github.com/openai/whisper (MIT).

Следующий этап — только после пробы: защищённая общая запись в Google Sheets.
Не помещать служебные ключи в браузер. Не возвращать неудобный вход при каждом
действии без обсуждения с Романом.
