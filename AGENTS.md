# Календарь отдела

- Общаться с Романом по-русски, пошагово. Для действий в UI указывать устройство и приложение.
- Сохранить интерфейс, меню и мобильное оформление версии 1.11.9 как исходный образец.
- Главный редактор — Роман. Остальной отдел смотрит и предлагает изменения.
- Будущие операторы редактируют только Google-таблицу. Код и интерфейс меняет
  только Роман; новых операторов пока не добавлять. Фоновая схема в AUTOSYNC.md.
- Основная база — Google Sheets, ссылка и схема работы в DEVELOPMENT.md.
- Не удалять тестовые записи без отдельного указания пользователя.
- Не добавлять ключи, расшифрованные экспорты или private/ в Git.
- Не считать правки в localStorage опубликованными: для отдела нужен новый data.enc.json.
- Перед изменением данных читать текущую таблицу и сохранять резервный снимок.
- Код версии 1.11.9 содержит миграции и встроенные мероприятия в normalizeDisplayData;
  учитывать их при сравнении таблицы, снимка и интерфейса.
- Проверка: node tools/check.cjs. Ручная проверка мобильного и настольного вида при изменениях интерфейса.
- Локальный запуск: node tools/serve.cjs, http://127.0.0.1:4173/.
