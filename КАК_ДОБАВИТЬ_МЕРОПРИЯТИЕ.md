# Добавление мероприятия — 09.11.2026

На телефоне или ноутбуке откройте дашборд отдела.

1. Мероприятия → + Мероприятие.
2. Выберите автора. Заполните название, дату, время и участников. Можно сначала раскрыть «Заполнить карточку из текста», ввести текст и нажать «Заполнить карточку»; это только заполняет поля и ещё не сохраняет запись.
3. Проверьте поля и нажмите «Добавить в общий календарь».
4. Дождитесь ответа. «Сохранено в Google Sheets» — общая таблица приняла запись. «Мероприятие опубликовано» — запись уже вошла в опубликованный снимок сайта.
5. Если запись принята таблицей, повторно её не добавляйте. Проверки публикации запланированы с 08:00 до 21:00 каждые пять минут, ночью — каждые 30 минут; запуск GitHub может задерживаться. Позже откройте «Импорт / экспорт» → «Получить свежие данные из общей базы». Эта кнопка получает опубликованный снимок, а не запускает сборку GitHub.

Для редактирования существующих данных: «Импорт / экспорт» → выбрать автора → «Редактировать общие записи» → сохранить на устройстве → «Загрузить изменения в Google Таблицу». Кнопка «Синхронизировать» отправляет накопленные изменения и проверяет их появление в снимке; при отсутствии локальных правок только получает снимок. «Сохранить изменения в файл» создаёт резервную копию и не публикует данные.

Версия 1.11.36: ответ сервера остаётся видимым на вкладке «Мероприятия» после закрытия карточки. Сама частота автоматической публикации этим обновлением не менялась.

## Как удалить мероприятие (версия 1.11.37)

На телефоне в дашборде откройте «Мероприятия». Нажмите «Удалить» рядом с нужной записью. Выберите, кто удаляет, проверьте название, дату и время, затем нажмите «Удалить» и подтвердите. Если есть другие неотправленные правки, сначала отправьте их в «Импорт / экспорт».

Вариант через текст: «+ Мероприятие» → «Заполнить карточку из текста» → написать «Удалить Тест» → «Заполнить карточку». Откроется поиск совпадений. Выберите автора и удалите точную запись. Также поиск доступен в разделе «Удалить мероприятие по названию».

Удаление отправляется в Google-таблицу сразу, а на других устройствах становится видимым после публикации снимка. В базе сохраняется статус «Отменена» для всех участников мероприятия. Это позволяет восстановить его и не удаляет остальные записи. Для восстановления используйте общий редактор событий и верните нужный статус (например, «План»).
