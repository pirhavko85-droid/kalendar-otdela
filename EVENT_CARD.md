# Добавление мероприятий из дашборда

Решение Романа от 08.11.2026: убрать голосовой ввод; оставить текстовую карточку
и прямое добавление в Google Sheets без входа и личных кодов.

Открыть «Мероприятия» → «+ Мероприятие». Заполнить название, дату, время,
выбрать участников, добавить комментарий и выбрать «Кто внёс». Нажать
«Добавить в общий календарь». Сначала подтверждается запись в Google Sheets,
затем автоматическая публикация GitHub по действующему расписанию. При наличии
общего ключа открытая карточка проверяет опубликованный снимок до 5 минут.

«Заполнить карточку из текста» — дополнительный раскрывающийся блок.
Он использует простые правила распознавания дат и времени, без микрофона,
моделей, платного API или отправки текста внешней нейросети.

Доступ простой и публичный, явно подтверждён Романом: любой посетитель может
добавить мероприятие и выбрать одну из трёх подписей. Это заявленный автор,
не подтверждённая личность. Google email и права Google Drive не проверяются.
На уровне Drive последним редактором может отображаться владелец скрипта;
выбранная подпись хранится в столбце «Кто внёс» и отображается у мероприятия.

Сервис может только добавлять строки фиксированного листа «События» фиксированной
базы. Методов изменения, удаления или чтения чужих файлов для посетителя нет.
Проверяются поля и ID сотрудников; участники объединяются в одно мероприятие.
Идентификатор запроса и проверка совпадающего названия/даты/времени защищают от
дублей. Есть глобальная блокировка и лимит 200 добавлений в сутки. Это не защита
от целенаправленных злоупотреблений публичным доступом. Отозвать режим можно,
архивировав deployment в Apps Script и убрав WRITE_URL из event-card.js.

Проект владельца:
https://script.google.com/home/projects/1eITsC44wllUQvkArpDUU1klE5Dh5DDCsFT1xWHsY-jbnGFQsAIi1WvYx/edit

Исходники сервиса: tools/event-writer. Развёртывается как USER_DEPLOYING,
ANYONE_ANONYMOUS. Scope spreadsheets нужен для записи; исходники фиксируют
единственный ID базы. Никаких Google/GitHub ключей в публичном JS нет.
Предыдущие строки не изменяются; перед append фиксируется снимок пустого целевого
диапазона в LAST_APPEND_BACKUP. Права на код проекта операторам не выдаются.

Проверки: node tools/check.cjs; node --test tools/event-writer.test.cjs
tools/voice-draft.test.cjs. Последний файл проверяет сохранённый текстовый парсер;
сам голосовой код удалён.
