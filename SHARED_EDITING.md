# Общее редактирование и многодневные мероприятия — 08.11.2026

Поручение Романа: данные отдела редактируют все, без привязки к Google-аккаунту; каждый указывает своё имя. Это заявленная подпись, не подтверждённая личность. Исходный код и права Google Drive не открываются участникам.

В «Импорт / экспорт» добавлены выбор автора, «Загрузить изменения в Google Таблицу», «Получить свежие данные из общей базы», «Синхронизировать», «Проверить отправку», «Сохранить изменения в файл». Последняя кнопка сохраняет локальный пакет; скачанный файл не означает публикацию. Общий ключ отдела сохранён.

Сервис общей записи расширяет существующий Apps Script и работает только с фиксированной таблицей и четырьмя листами: сотрудники, события, задачи, дни рождения. Новые записи и правки передаются с исходными значениями. Изменённая другим участником запись отклоняется как конфликт; чужие правки не перезаписываются. Формулы из пользовательского текста сохраняются как текст. Формулы служебных колонок не меняются. До записи сохраняются исходные строки, при ошибке выполняется откат. Есть блокировка, проверка чтением после записи, журнал запросов, дневной лимит. Неизвестный исход блокирует слепой повтор и проверяется отдельной кнопкой. Удаление общей записи этим механизмом не поддерживается; используйте отмену события/задачи. Локальное удаление не отправляется молча.

В Google появляются колонки «Кто изменил» и «Когда изменено»; авторство отображается в раскрывающейся истории интерфейса. Получение опубликованного снимка блокируется при неотправленных правках. После подтверждённой записи локальные новые значения сохраняются, пока старый снимок ещё публикуется. «Синхронизировать» после записи проверяет появление правок в снимке до 5 минут. Обычная отправка не запускает второй GitHub-сборщик: используется прежнее расписание публикации.

«Кто где»: нерабочий день по производственному календарю означает «Выходной» без отдельной записи. Явный выход на службу или наряд учитываются как служба. Отменённые события не действуют. Счётчики и список сотрудников используют один расчёт. Это не добавляет вымышленные записи о фактической службе Романа или других людей.

Мероприятие с датами начала/окончания считается один раз, отображается ежедневно в календаре и остаётся текущим до окончания. Два ранее заведённых переезда 9–13 и 16–20 ноября, разбитые на 10 дневных строк, объединяются по подтверждённым ID без удаления строк и без создания новых дублей. В истории показан полный период. Произвольные одинаковые названия разных недель автоматически не склеиваются.

Проверки: node tools/check.cjs; node --test tools/*.test.cjs. Рабочий сайт публикуется отдельным GitHub Pages шагом. Состояние развёртывания и сквозная проверка фиксируются после публикации, не выводятся только из прохождения тестов.

## Автоматический обмен — версия 1.11.40

После сохранения карточки не требуются дополнительные действия в «Импорт / экспорт».
Общие локальные правки отправляются автоматически с выбранным автором. Результат
подтверждается Google Sheets, затем ожидается публикация и автоматически загружается
зашифрованный снимок. Статус виден прямо в «Мероприятиях». Ручные кнопки свёрнуты
в «Ручные действия и резервная копия»; «Импорт / экспорт» перенесён первым в меню.

Ожидающая публикация проверяется открытой видимой страницей каждые 15 секунд,
обычные свежие данные — раз в минуту. Возвращение на страницу и восстановление сети
вызывают проверку. Запросы сериализованы; старый снимок не откатывает подтверждённые
правки. Квитанции новых мероприятий сверяются с реальным опубликованным снимком,
а не с локальными записями. Ожидание сохраняется при перезагрузке без ограничения
в пять минут. Неизвестный исход общей правки проверяется по ID; повтор добавления
использует тот же ID запроса. Конфликт приостанавливает автоматическую отправку.
Новая карточка после потери ответа восстанавливается из локального хранилища.

Это обновление клиента не меняет серверное расписание и не гарантирует мгновенную
публикацию. Права Google Drive и сервис записи не расширены. Бизнес-записи при
проверке не создавались и не отменялись. Автоматические проверки покрыты отдельными
тестами с подставным транспортом; реальные данные для тестирования не меняются.

## Сверка конфликтов — 1.11.41

Повторная проверка отклонённой правки больше не отправляет её снова. При паузе
разрешено чтение свежего снимка: для каждой операции сверяются именно поля,
которые пользователь менял. Если они уже имеют нужные значения, операция
снимается с очереди, а другие свежие поля сохраняются из общей версии.
Оставшиеся расхождения сохраняются локально и не отправляются автоматически.

В «Мероприятиях» и панели обмена доступно «Принять общую версию». После свежего
чтения и подтверждения пользователя несохранённые правки заменяются общей
версией. Перед заменой сохраняется departmentConflictBackupV1 (db + очередь +
время); при ошибке резервирования замена запрещена. Это действие не пишет
в Google Sheets. Повторное редактирование выполняется от актуальных значений.

При проверке сообщения со скриншота 999.jpg прочитаны таблица и опубликованный
снимок: указанное тестовое мероприятие уже отменено. Данные не изменялись.
Проверки: 51 тест, включая повторную отмену, настоящий конфликт и перезапуск.
