# Мероприятия с телефона — 18.11.2026
Версия интерфейса: 1.11.55.

1. Откройте календарь отдела в браузере телефона, подключите свой имеющийся общий ключ.
2. Во вкладке «Мероприятия» нажмите «+ Мероприятие». Выберите автора, заполните название, дату, время и участников. Нажмите «Добавить в общий календарь».
3. Дождитесь страницы Google с подтверждением записи. Нажмите «Вернуться в календарь отдела».
4. Для исправления нажмите у нужной записи «Удалить / изменить», выберите автора и «Изменить». Исправьте поля и сохраните. Подтверждение придёт тем же способом.
5. Для удаления нажмите «Удалить», затем «Подтвердить удаление» прямо в карточке. «Отмена» отменяет намерение удаления. В таблице запись останется отменённой для восстановления, из календаря исчезнет для всех.

Google-вход не требуется. Автор выбирается явно — это подпись. Отправка сохраняет запись в общей таблице, затем автоматически запускается публикация сайта. Обычно это занимает несколько минут; расписание проверок — круглосуточно каждые пять минут, GitHub может задерживать запуск. Не нужно повторно создавать мероприятие и переходить в импорт/экспорт. Открытый календарь получает свежий снимок автоматически.

При сетевой ошибке запрос остаётся в «Неподтверждённых черновиках». Повторяйте оттуда: исходный ID защищает от дубликатов. «+ Мероприятие» открывает новую доступную форму. Сообщение об успехе показывается после подтверждения Google, а черновик исчезает после получения общей опубликованной версии.

Проверено: реальное добавление, исправление названия/дат/времени/участников и удаление; все семь авторов в автоматических тестах. Результаты проверены чтением Google Sheets. Проверка без Google-аккаунта также прошла. Физические телефоны сотрудников удалённо не проверялись.
