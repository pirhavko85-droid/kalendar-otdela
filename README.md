# Календарь отдела

Мобильное веб-приложение для учёта событий и задач небольшого отдела.

## Важно о данных
Репозиторий публичный, поэтому реальные персональные данные и служебные сведения **не хранятся в GitHub**. Приложение хранит рабочие данные только локально в браузере (localStorage). Есть экспорт/импорт резервной копии в JSON.

## Разделы
- Сегодня / Кто где
- Календарь
- События
- Отпуска
- Наряды
- Командировки
- Больничные
- Задачи
- Статистика
- Сотрудники
- Импорт / экспорт

## Следующий этап
Защищённая синхронизация с Google Sheets через отдельный промежуточный слой, чтобы не публиковать исходную таблицу и персональные сведения.
